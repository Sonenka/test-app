Сделала загрузку матчей, карточки с командами, счетом, статусами на русском и местным временем. Добавила загрузку, пустые состояния, попап ошибки с повторной попыткой, фильтры и обновление; исправила избранное и таймер.

Дополнительно сделала поиск по клубу, сохранение избранного, отдельную категорию избранных, приоритет отмеченных матчей, секцию «Сейчас в игре» и две темы с сохранением выбора. Добавила 9 автоматических тестов фильтрации. Не успела проверить приложение на физическом устройстве, т.к. различались версии Expo Go

## Решения

- В «Предстоящие» включила `scheduled` и `postponed`: перенесенный матч еще сыграют, даже если новая дата неизвестна. В «Завершенные» включила только `finished`. `live`, `cancelled` и неизвестные статусы оставила доступными в «Все». Ориентировалась на статус сервера, а не на дату (в примере есть запланированные матчи с уже прошедшим временем начала).
- Для `live` выделила секцию «Сейчас в игре», остальные матчи показываю отдельно. Внутри каждой секции сначала вывожу избранные, затем остальные, сохраняя порядок сервера внутри групп. Поиск и категорию применяю до разделения на секции, поэтому матчи не дублируются.
- Счет проверяю по наличию объекта, поэтому `0:0` не теряется; отсутствие счета обозначаю тире. Для отсутствующей или некорректной даты вывожу «Дата и время уточняются», для неизвестного статуса - «Статус неизвестен». Дату форматирую через `Intl.DateTimeFormat` без заданного `timeZone`, чтобы использовать часовой пояс устройства.
- При обновлении показываю спиннер вместо списка и блокирую кнопку. Сохраняю поиск, категорию и избранное; после ошибки возвращаю предыдущие данные и предлагаю повторить запрос в попапе. Время последней загрузки меняю только после успешного ответа; запрос отменяю при размонтировании или по тайм-ауту 15 секунд.
- Поиск сделала по части названия хозяев или гостей, без учета регистра и пробелов по краям. Добавила очистку и отдельное сообщение при отсутствии совпадений.
- Для сохранения избранного и темы добавила `@react-native-async-storage/async-storage` через `expo install`. Храню только id матчей и выбор темы; перед записью избранного дожидаюсь начального чтения, учитываю ранние нажатия и выполняю записи последовательно. При ошибке чтения избранное продолжает работать без перезаписи непрочитанных данных.
- Для оформления использовала общую палитру светлой и темной тем. Логотип и переключатель вынесла в неподвижный хедер, остальное содержимое - в один `SectionList`; в браузере закрепила место под скроллбар, чтобы категории не смещались при его исчезновении. Для live добавила плавно мигающую точку.

## Баги из части 2

1. **Звездочки.** Проверка неправильно понимала результат поиска: если матча в избранном не было, она считала, что он есть, а для первого матча в списке - наоборот. При нажатии менялся существующий массив, поэтому React мог не заметить изменение и не обновить звездочку. Заменила проверку на `includes`, а при добавлении и удалении стала создавать новый массив на основе последнего состояния.
2. **«Обновлено N сек назад».** Таймер каждый раз брал начальный ноль и прибавлял единицу, поэтому число застывало на `1`; время новой загрузки он вообще не учитывал. Теперь считаю, сколько секунд прошло с последней успешной загрузки, поэтому после обновления отсчет начинается заново. Также добавила остановку старого таймера при его замене и при уходе с экрана.

## Как я использовала ИИ

Использовала Codex для реализации, разбора ошибок и проверок; задавала этапы, проверяла результат и сама делала коммиты. Через Codex сверяла API с документацией Expo SDK 57, запускала TypeScript и тесты, проверяла интерфейс в браузере.

По ходу заметила недостатки предложенного оформления: сломалась прокрутка, верхний отступ мешал шапке, надпись на кнопке попапа сместилась влево. Попросила исправить эти случаи.

В браузере через Codex проверила фильтры, поиск, сохранение и удаление избранного после перезагрузки, отсчет и сброс таймера, темы и ширину 390 px. Логику ошибок HTTP, повторной попытки, пустого ответа и неудачного обновления дополнительно проверила через Codex с подставными ответами.
